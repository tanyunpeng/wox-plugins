# Bitwarden 密码库（Wox 插件）

在 Wox 里搜 Bitwarden / Vaultwarden 密码库，把用户名、密码、验证码复制出来。只读：不新建、不修改条目。

触发词 `pw`。解锁在任何一次 `pw` 查询里完成，唯一的命令是 `pw lock`。Windows、Linux、macOS 都能用。

## 功能

- `pw <关键词>` 搜条目名称、用户名和网址。结果按这个顺序排：收藏的优先，其次名称命中强于用户名命中强于
  网址命中，同分再看你常用的次数，最后按名称。
- 回车复制密码。**复制用户名**、**复制网址**、**复制验证码**、**复制字段：<名>**（自定义字段，最多两
  个）、**显示/隐藏密码**都是按钮，出现在行内、动作栏和预览面板上。没有可复制密钥的条目，默认动作退化成
  **复制名称**，保证回车始终有着落。不敲键、不点击就不会复制任何东西。
- 验证码在本地算出来，不联网；预览里显示当前这个码还剩多久有效。
- **显示/隐藏密码**切换该行预览里密码和备注是掩码还是明文。默认是掩码，重新查一次就又盖上。
- 预览面板按条目实际带有的字段列出：用户名、网址、掩码后的密码、当前验证码和有效期、备注、所属文件夹、
  所有者（自己的库还是某个组织）、更新时间。文案跟随 Wox 的界面语言。
- 还没解锁时，任何 `pw` 查询都会弹出解锁表单：邮箱预填上次登录的账号，主密码那一格输入时不显示明文。
- `pw lock` 只丢弃内存里的密钥、保留登录会话，之后再敲一次 `pw` 重新输主密码就能解锁。

## 配置

1. 这个插件不在 Wox 商店里，装法见仓库根目录的 README。
2. 在插件设置里填服务器地址（Wox 设置 → 插件 → Bitwarden 密码库）。默认是官方云
   `https://vault.bitwarden.com`，自建 Vaultwarden 换成你自己的地址，不带 `/api` 或 `/identity` 后缀。
   这一项没填之前，Wox 会自己弹出来让你补上。
3. 敲 `pw`，填账号邮箱和主密码解锁。整个密码库取回来一次，之后都在你这台机器上解密和使用。

## 隐私与安全

- 主密码、登录令牌和所有解出来的密钥只在你这次运行里存在，不写文件、不进设置；重启 Wox 就退出登录，
  `pw lock` 随时手动丢弃。
- 搜索时密码、验证码密钥和备注都还是密文，你对某一条按了哪个按钮才解密哪个字段。
- 会跟着 Wox 账号同步到同账号其他设备的只有服务器地址和邮箱；密码、验证码、备注、使用记录都不在这个范围
  里，插件也不会把这些内容发给你的密码库服务器之外的任何地方。
- 唯一的例外是网站图标：为了显示图标，插件会去访问条目里记着的那个网站、每个域名取一次图标，这个请求里
  没有你的账号和库内容；拿不到就用默认图标。
- 你复制过哪些条目、复制了几次，只记次数不记内容，删掉这些记录只是排序退回默认。
- 别的插件或 AI 调用方拿不到"替你复制密码"的能力。**复制网址**只把地址放进剪贴板，不会替你打开浏览器，
  预览里的链接交给 Wox 处理。
