# 待办（Wox 插件）

在 Wox 启动器里记待办：一行一条，回车勾选完成，截止日期从列表里挑。不开网页面板、不弹二级窗口，所有操作都在启动器里完成。

触发词 `td`。唯一的命令是 `td new`。Windows、Linux、macOS 都能用。

## 功能

- `td <关键词>` 在列表里过滤标题。
- 一行怎么读：左边的圆圈是完成状态（灰圈未完成、绿底白勾已完成）；标题下面那行是截止日期；行尾标签依次是
  `今天` / `逾期`（勾选之后仍然保留）和 `完成于 MM-DD HH:mm`。
- 排序：逾期 → 今天 → 明天 → 更晚 → 无截止日期（置底），同一天按标题。已完成不再沉底，它留在自己日期该在的位置。
- 筛选：`状态` 三档 全部 / 待处理 / 已完成，默认全部。切到「已完成」时改按完成时间倒序，最近完成的在最上面。
  筛选条的展开与收起是 Wox 自己的界面状态（插件无权让它默认展开），点「筛选」或按 `Ctrl+F` 打开。
- **勾选完成 / 重新打开**：回车，或工具栏按钮。行原地改涂装，列表不重载。
- **新建**：只有命令。`td new 买牛奶` 回车即建。Wox 解析命令**要求末尾有空格**——`td new` 会被当成搜索词，
  `td new ` 或 `td new 买牛奶` 才是命令；敲 `td ` 时 Wox 会把命令行列出来，点一下它自己补上那个空格。
- **编辑**：在动作面板（`Ctrl+K`）里，或按 `Ctrl+Shift+E`（macOS `⌘⇧E`）。表单只有一个框：待办内容。
- **设置截止日期**：工具栏按钮或 `Ctrl+Enter`（macOS `⌘↵`）。它不弹菜单，而是把整列换成日期行：首行「返回」，
  次行「无截止时间」，往后是 今天 / 明天 / 后天 和接下来 14 天，副标题带星期。回车写回并回到列表，光标跟着那条任务。
- **删除**：在动作面板里，或按 `Ctrl+Shift+D`（macOS `⌘⇧D`）。**没有二次确认**，删了就删了。

## 数据与同步

- 任务存在 Wox 的插件设置里，一个未声明的键 `tasks`，整块 JSON。插件设置页是空的：这个插件没有需要调的选项。
- 这份数据跟着你的 Wox 账号云同步到其它设备。写入是整块「读-改-写」，**两台设备同时改会丢后保存的那一份**——
  这是已知取舍，只在一台机器上用不受影响。
- 每次保存都会在 Wox 的同步变更历史里留一条记录，误删了可以从那里看到当时的内容。

## 已知边界

- 勾选完成后，筛选条上的计数不会立刻跟着变（筛选只能随查询返回），下次输入或刷新时自愈。
- 顺序是靠给每行打递减分数保住的，分数上限 100（SDK 口径），**超过 100 行时尾部会并列**，那时 Wox 会退回按标题排。
- 日期选择器只覆盖今天起 14 天；更远的日期这里选不到。
- 在全局搜索里（不带 `td`）出现的待办行，排序由 Wox 决定，不保证日期顺序。
- 结果行的图标只是图片，不是控件，点不动；勾选只能靠回车或按钮。

## 开发与验证

```bash
npm test        # 行为测试，跑在假的宿主 API 上，日期跟着系统时钟走
npm run check   # 静态门禁：manifest 字段、双语 i18n 键双向对齐、构建脚本约束
npm run package # 产出 dist/ 和 wox.plugin.todo.wox
```

把本目录登记成 Wox 的「本地插件目录」后，改完只需 `npm run package`，宿主几秒内自动加载新版本。
