# 提示词（Wox 插件）

把常用的提示词存在 Wox 里，`pt` 一敲、回车复制正文。

触发词 `pt`。Windows、Linux、macOS 都能用。

## 功能

- `pt <关键词>` 在标题、说明和正文里筛，不区分大小写；不输关键词就是全量列表。
- 回车**复制到剪贴板**：复制的是正文全文，复制完收起 Wox 窗口，可以直接粘进任何输入框。
- 预览面板显示正文全文；填了说明的行挂一个「说明」标签，鼠标停上去看完整说明。行副标题优先用说明，
  没说明就取正文首行截断。
- 起始页会回显你最近用过的模板，常用的一条不用搜。

## 设置

先走一遍：Wox 设置 → 插件 → 提示词，在模板表格里加几条（标题 / 内容 / 说明），回 Wox 输 `pt` 就能看到。

模板存在插件设置里的一张表格（`提示词模板`）：

| 列 | 作用 |
| --- | --- |
| 标题 | 搜索和展示用 |
| 内容 | 回车复制的正文 |
| 说明 | 显示在结果行副标题和「说明」标签里，可留空 |

一条都没有时，`pt` 显示一行「还没有提示词模板」，副标题直接告诉你去哪儿加。

## 隐私与安全

- 模板跟着你的 Wox 账号同步到同账号的其他机器，除此之外它只待在这台机器上——插件不联网。
- 内容进剪贴板只发生在你按回车或点复制的那一刻，别的插件或 AI 调用方借不到这个动作。
